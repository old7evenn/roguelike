# Roadmap

Робочий план для реалізації. Підсумковий чекліст для здачі — у README, розділ «План і прогрес».
Після кожного завершеного пункту відмічай його тут і в README.

## Етап 1 — Basic ✅

- [x] Генерація «кімнати + коридори» з seed, 10 поверхів, перемога
- [x] Архітектура: engine / world / generation / ui, Command, Type Object, Strategy, Observer, State
- [x] Biome, Vitest, CI, деплой на GitHub Pages

## Етап 2 — Standard (оцінка 4)

### 2.1 Монстри ✅
- [x] `Breed` — Type Object: назва, `maxHp`, `attack`, `defense`, поведінка, глибина появи. Таблиця порід у `world/breeds.ts`, гліфи в `ui/theme.ts`.
- [x] `Monster extends Actor` з `hp`; `nextAction` делегує `Behavior` (Strategy).
- [x] Поведінки: `ChaseBehavior` (йде вниз по `distanceMap` від героя, якщо бачить або чує), `WanderBehavior`.
- [x] `Stage.actorAt(pos)`; актори блокують прохід.
- [x] Спавн монстрів на поверсі з детермінованого `Rng` (окремий seed від генерації карти); глибші поверхи — сильніші породи.

### 2.2 Бій ✅
- [x] `hp`, `attack`, `defense` у героя.
- [x] `AttackAction`: `WalkAction` у клітинку з актором повертає `alternate(new AttackAction(...))`.
- [x] Смерть монстра прибирає його зі `Stage`; смерть героя → подія `defeat` → `GameOverScreen`.
- [x] Події `attack`/`death` у `GameEvents` для журналу.
- [x] Тести: удар зменшує HP, смерть, детермінізм бою для того самого seed.

### 2.3 Предмети ✅
- [x] `ItemType` — Type Object (зілля лікування, зброя з бонусом до атаки).
- [x] Предмети лежать на `Stage`; `PickUpAction` при кроці на предмет. Клавіша `G` не знадобилась: інвентар без ліміту, тож предмет підбирається завжди.
- [x] Інвентар героя; `UseItemAction`.
- [x] Екран інвентарю. Тут `Ui` отримує стек екранів (`push`/`pop`), бо інвентар відкривається поверх гри.

### 2.4 UI ✅
- [x] Журнал з кількох останніх повідомлень замість одного рядка: `MessageLog` у `ui/`, повтори згортаються в «×3», нове виділено.
- [x] HP у статус-барі.

### 2.5 Перевірка
- [ ] Баланс: гру реально пройти, але не тривіально.
- [ ] Гру пройшла хоча б одна людина, крім автора.

## Етап 3 — Advanced (оцінка 5): обрати 2–3

- [ ] Звук через Web Audio API.
